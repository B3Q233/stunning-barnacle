# TPA 攻击实验可视化（demo v3）

纯前端单页：以「实验卡」为单位管理多个攻击实验（`history.json` +
`*_comparison.json`），输出每轮指标折线图与 Clean vs Poisoned 直方图；
指标可勾选显隐、自定义颜色；使用 Nature 顶刊色板与期刊风格布局。

## 打开方式

直接用浏览器打开 `index.html`（`file://` 即可，无需服务器）。

## 使用方法

### 添加实验卡

- 点击「＋ 添加实验卡」打开弹窗，两种方式任选：
  - 输入名称后确定；
  - 点「导入实验路径自动命名」选择实验目录，自动按
    「攻击方法-实验时间」命名（如 `random-2026-08-15-07-23`）并读入数据。

### 实验卡内操作（导入只能在卡内进行）

- 卡头：`[勾选框] 名称` + 数据状态（history ✓ / comparison ✓）+ 按钮：
  - 改名：弹窗输入新名称；
  - 重置 H / 重置 C：只清空该卡的 history / comparison；
  - 删除：确认弹窗后移除该卡。
- 卡体（无数据时）导入区：
  - 「导入实验路径」：选整个实验目录，自动读入 `history.json` 与
    `*_comparison.json`（名称若为默认「实验 N」则自动改为「方法-时间」）；
  - `history.json` / `comparison` 两个文件入口：在卡内单独选择文件。
- 卡体（有数据后）指标行：每指标 checkbox（默认全选）+ 颜色选择器，
  修改即时重绘。
- 只有勾选的实验卡参与图表渲染。

### 图表

- 折线图：同一指标按实验拆线，x 轴为所有实验 epoch 并集；
  标题、图例、绘图区三层分离（`title.top=10`、`legend.top=44`、
  `grid.top=96`），系列再多也不会互相挤压重叠。
- 直方图：x 轴为实验，每个实验一组 Clean / Poisoned 柱，柱色按实验的
  指标自定义色逐点着色，标签水平显示。

### 导出

- 「导出当前实验卡标准 JSON」：下载当前实验卡的 `{epoch: {指标}}` 文件
  （点卡头名称可切换当前实验卡）。

## 测试

```bash
node --test TPA/visualization/tests/
```

## 手动验证清单

- 添加实验卡：输入名称确认；再点「＋ 添加实验卡」选「导入实验路径」，
  自动命名并读入数据。
- 卡内单独导入 history / comparison 文件；重置 H / C 只影响对应卡。
- 折线图标题与图例不重叠，取消勾选指标/改颜色即时生效。
- 直方图 Clean/Poisoned 分组、标签水平；取消勾选实验卡后曲线与柱消失。
- 删除弹窗确认后移除；导出 JSON 为 `{"1": {...}, ...}`。
