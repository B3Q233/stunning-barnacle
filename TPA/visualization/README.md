# TPA 攻击实验可视化（demo v2）

纯前端单页：支持多个实验选项卡对比。每个选项卡承载一次攻击实验
（`history.json` + `*_comparison.json`），输出每轮指标折线图与
Clean vs Poisoned 直方图；指标可勾选显隐、自定义颜色。

## 打开方式

直接用浏览器打开 `index.html`（`file://` 即可，无需服务器）。

## 使用方法

### 选项卡

- 左侧「+ 新建选项卡」：弹窗输入名称（默认「实验 N」，可随时点 ✎ 改名）。
- 每个选项卡条目：`[勾选框] 名称` + 操作按钮：
  - `✎` 改名；
  - `↺H` 重置该选项卡的 history；
  - `↺C` 重置该选项卡的 comparison；
  - `×` 删除选项卡。
- 只有**勾选**的选项卡参与渲染，其指标选项才会出现在上方卡牌中。

### 导入数据（导入必须落在选项卡内）

- 「导入实验目录」：选择整个实验目录（如
  `TPA/attacks/random/outputs/ml100k/lightgcn/2026-08-15-07-23/`），自动
  读取目录下 `history.json` 与 `*_comparison.json`，并按
  「攻击方法-实验时间」自动命名（如 `random-2026-08-15-07-23`）。
- 「导入文件（多选）」：可同时选择 `history.json` 与 `attack_comparison.json`。
- 拖拽文件到虚线框等同「导入文件」。
- 导入规则：每次导入都落到新建/空选项卡；当前选项卡已有数据时需先新建选项卡。

### 卡牌（指标控制）

- 每个实验一段，列出该实验全部指标：checkbox（默认全选）+ 颜色选择器。
- 取消勾选即隐藏对应曲线/柱组；改颜色即时生效。

### 图表

- 折线图：同一指标按实验拆线（如 `recall@10-random-2026-08-15-07-23`），
  x 轴为所有实验 epoch 并集。
- 直方图：x 轴为实验，每个实验一组 Clean / Poisoned 柱；对比指标
  （模型效用 / 目标命中）在卡牌中勾选显隐，标签水平显示。
- 未勾选含数据选项卡时图表显示占位提示。

### 导出

- 「导出当前选项卡标准 JSON」：下载当前激活选项卡的 `{epoch: {指标}}` 文件。

## 测试

```bash
node --test TPA/visualization/tests/
```

## 手动验证清单

- 导入两个实验目录（如 random 的 `2026-08-15-07-23` 与 pgd 的
  `2026-08-09-23-33`），自动命名为「攻击方法-时间」。
- 折线图同一指标按实验拆线；取消勾选某指标、改颜色即时生效。
- 直方图 x 轴为实验、Clean/Poisoned 分组、标签水平不倾斜。
- 取消勾选某个选项卡后，其卡牌选项与曲线消失；重新勾选恢复。
- 重置 history / comparison 只影响对应选项卡；删除选项卡确认后移除。
- 导入到已有数据的选项卡会提示先新建；导出 JSON 为 `{"1": {...}, ...}`。
