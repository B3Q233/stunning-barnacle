# Paper Tutor 教学范例（可套用模板）

本文件给四个可复用的教学范例。SKILL.md 的 Step 5.5 强制要求其中对应的结构，生成
derivation.html 时直接按这些模式填充论文内容。

## 1. 概念推导四步（以点积为例）

背景公式 `\hat r_{ui} = p_u^\top q_i` 不能直接丢出来，必须做概念推导：

**Step 1 定义用户向量**
用户不是一个编号，而是一个长度为 k 的兴趣向量：
\(p_u = [0.2, 0.8, 0.1]\)。
例子：第一维表示动作片兴趣，第二维爱情片，第三维喜剧片。

**Step 2 定义物品向量**
每个电影也变成同维度表示：
\(q_i = [0.6, 0.7, 0.2]\)。

**Step 3 为什么用点积**
点积 = 每个兴趣维度分别打分再相加：
\(0.2\times0.6 + 0.8\times0.7 + 0.1\times0.2\)。

**Step 4 推广成矩阵形式**
于是得到论文公式：
\(\hat r_{ui} = p_u^\top q_i\)。

注意：这是概念推导（为什么这样建模），不是代数推导。

## 2. 例子 → 数学 → 回到例子（以 Softmax 为例）

**生活例子**：三个电影得分 2、4、6，即 \(z=[2,4,6]\)。

**为什么不能直接当概率**：和不是 1（2+4+6=12），而且允许负数。

**指数放大**：\(e^z = [7.4, 54.6, 403]\)，保证非负、放大差异。

**归一化**：
\(P_i = \frac{e^{z_i}}{\sum_j e^{z_j}}\)。

**回到例子**：算出三个概率并说明“得分 6 的电影占绝大多数概率”。

## 3. Why Card 模板（自适应：问题集合按来源自动选择；以 Optimization 为例）

出现一模一样的问题集合：

## 4. 损失函数三问（以 WMF 损失为例）

公式：
\(L = \sum_{u,i} c_{ui}(p_{ui} - x_u^\top y_i)^2 + \lambda(\|X\|^2 + \|Y\|^2)\)。

不要直接讲，先拆符号表（符号 / 意义 / 为什么需要）：

| 符号 | 意义 | 为什么需要 |
|---|---|---|
| p_ui | 是否发生交互（标签） | 二值化的偏好目标 |
| c_ui | 置信度 | 隐式反馈可靠程度不同 |
| x_u | 用户向量 | 学习兴趣 |
| y_i | 物品向量 | 学习属性 |
| λ | 正则化 | 防止过拟合 |

再回答三个问题：
- **为什么平方**：平方误差对大偏差惩罚更重、处处可导，配合凸优化有闭式解。
- **为什么乘置信度**：高置信观测（如反复观看）应比低置信（如一次误点）更影响拟合。
- **为什么最后加正则**：因子自由度过高会过拟合；λ 惩罚因子大小，由交叉验证决定。

## 5. 连续等式跳步的合规写法

禁止：

```
A = B
A = C
```

必须写成（一个等式 + 一句解释 + 一个理由）：

```
A = B
（解释：这里把 B 代入第 1 步……）
A = C
```

结构检测规则：两个显示公式之间必须有至少一句解释文本，否则判“连续等式缺少推导说明”。

## 6. 伴随式数值例子贯穿（以 WMF/ALS 为例）

禁止把例子集中成一个模块。正确做法：同一组数字沿着推导逐步演化，每个例子只服务
当前一步。

| 推导位置 | 出现的例子 | 目的 |
|---|---|---|
| 定义置信度 c_ui = 1+αr | 一个点击=3 的样本，取 α=1 → c=4 | 理解 α 的作用 |
| 构造 C 矩阵 | 对角线 4、1（两个物品：看过/没看过） | 为什么是对角矩阵 |
| 写损失函数 | 一个用户两个物品 | 每项来自哪里 |
| 求导 | 保留同一个例子 | 看梯度如何变化 |
| 闭式解 | 最后才算逆矩阵 | 得到最终结果 |

章节结构示例（阅读顺序：动机 → 微型例子 → 推导一步 → 回到论文）：

```
3.1 点积预测
 ├─ 为什么需要预测？
 ├─ 例子：用户=[2,1]
 ├─ 推导
 └─ 得到分数 8
3.2 加权损失
 ├─ 为什么普通 MF 不够？
 ├─ 同一个用户、同两个物品
 ├─ 引入置信度 4 和 1
 └─ 推导新的损失
3.3 ALS
 ├─ 继续沿用上面的矩阵
 ├─ 求导
 ├─ 闭式解
 └─ 验证结果
```

关键原则：同一个例子贯穿，而不是一次性讲完；读者是“跟着论文走”，不是“切换到例题模式”。

**状态连续**：同章例子的变量名、数值与语义默认继承上一节，除非明确声明“新的例子”；
不要在下一节突然换成 [1,4]，让读者重建上下文。

**Example Continuity（增量推进）**：一个章节只有一组主例子——

| 小节 | 新增 |
|---|---|
| 3.1 | r（原始点击次数） |
| 3.2 | p（偏好） |
| 3.3 | c（置信度） |
| 3.4 | C（对角置信度矩阵） |
| 3.5 | ALS（用同一个 C 求解） |

## 7. Formula Teaching Flow（固定阅读顺序）

每个公式必须按下面顺序教学：

1. 提出问题（为什么需要这个公式）
2. 微型例子（2–5 行，可手算，只覆盖当前步）
3. 局部符号（仅当前公式涉及）
4. Formula Source Level（这是定义/优化/变形……）
5. Why Card（按来源自动裁剪）
6. 一步一解释推导
7. 回到论文（它影响了哪一个实验）

动机永远在数学前面。

## 8. Theory Link（实验是论文证据）

每个实验必须引用对应公式，格式：

- 对应公式：Eq.(3)
- 验证假设：置信度加权有效
- 实验结果：8.56% vs 10.49%
- 结论：支持 / 不支持

实验不是证明模型“好”，而是在验证前面哪条数学设计。

## 9. Matrix Example Representation（矩阵例子规范：以 WMF 式 (4) 为例）

禁止只写 `A = 4×1² + 1×0.5² = 4.25`。必须从对象开始：

假设：
- \(Y = \begin{bmatrix}1\\0.5\end{bmatrix}\in\mathbb{R}^{2\times1}\)（两个物品的一维隐因子）；
- \(C^u = \begin{bmatrix}4&0\\0&1\end{bmatrix}\)（物品 1 点击过、可信度 4；物品 2 未点击、最低可信度 1）；
- \(p(u) = \begin{bmatrix}1\\0\end{bmatrix}\)。

计算 YᵀCᵘY：
- 第一步：\(C^uY = \begin{bmatrix}4&0\\0&1\end{bmatrix}\begin{bmatrix}1\\0.5\end{bmatrix} = \begin{bmatrix}4\\0.5\end{bmatrix}\)；
- 第二步：\(Y^\top(C^uY) = \begin{bmatrix}1&0.5\end{bmatrix}\begin{bmatrix}4\\0.5\end{bmatrix} = 1\times4 + 0.5\times0.5 = 4.25\)。

计算 YᵀCᵘp(u)：
- \(C^up(u) = \begin{bmatrix}4\\0\end{bmatrix}\)；
- \(Y^\top C^u p(u) = \begin{bmatrix}1&0.5\end{bmatrix}\begin{bmatrix}4\\0\end{bmatrix} = 4\)。

最终：\(x_u = \frac{4}{4.25+\lambda}\)（正规方程左侧矩阵项的标量化结果 / 闭式解系数项；
\(\lambda=0.01\) 时 \(\approx 0.9390\)）。

读者看到的是 Y, C, p → 矩阵乘法 → 数值 → 闭式解，而不是 A=4.25 突然出现。
