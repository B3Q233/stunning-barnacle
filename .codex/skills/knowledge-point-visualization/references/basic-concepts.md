# 基础概念覆盖清单（Basic Concept Coverage）

目的：生成任何“讲解/推导型 HTML”（如论文推导可视化页）之前，逐项做覆盖检查。
凡在公式或正文中出现过的概念，必须在页面中找到高中水平的最小解释，禁止“默认读者会”。

## 检查规则

1. 把缺失的概念集中写进一个“基础工具箱”小节（例如 `1.0 基础工具箱`）。
2. 每个概念给出：直观定义 + 最小公式（若需要）+ 在论文哪里用到。
3. 后续章节用到时只引用、不重复解释。
4. 概念若在输出中出现但清单中没有，说明清单需要扩充——扩充后回写本文件。
