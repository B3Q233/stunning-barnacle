# 证据与事实来源

## 优先级

`源代码事实 > 配置文件 > 可执行命令验证 > README > 论文 > 推断`

## 证据状态

- **源码确认**：可定位到实际分支、函数、类、参数解析或文件读取逻辑。
- **配置确认**：配置文件直接给出值，但未确认运行时是否覆盖。
- **文档声明**：README、注释或发布说明声称，但源码未完全核对。
- **命令验证**：轻量只读命令实际成功，记录命令和输出摘要。
- **合理推断**：由多个证据推导，必须写明依据。
- **无法确认**：现有材料不能判断，必须提出补充信息。

## 冲突处理

源码中的实际默认值覆盖 README 示例；配置加载后的覆盖顺序覆盖配置原文；论文只用于实验语义映射，不用于证明命令可运行。记录冲突，不静默选择。
