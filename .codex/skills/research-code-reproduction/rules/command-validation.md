# 命令验证规则

## 允许的只读检查

目录/文件列表、文本搜索、Git 元数据读取、版本查询、依赖 import 检查、`--help`（确认不会触发初始化）、路径存在性检查和配置解析。

## 禁止的默认操作

训练、推理、评估、下载数据/权重、解压大文件、安装/升级依赖、创建环境、编译扩展、修改配置、生成 checkpoint、写日志/缓存/结果或改变权限。

## 判断规则

不因命令名称含 `test`、`eval`、`dry-run` 或 `demo` 就视为安全；先读入口代码确认副作用。无法确认时写“未执行”，并说明阻碍。

## 命令记录

每条命令记录来源、工作目录、参数、验证状态和限制；不要伪造执行结果。
