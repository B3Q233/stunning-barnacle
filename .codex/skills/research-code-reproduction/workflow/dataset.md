# 数据集分析

## 检查目标

定位数据集名称、来源、下载方式、目录结构、文件格式、预处理步骤、划分规则和代码读取路径。

## 优先位置

搜索 Dataset/DataLoader 类、数据根目录参数、文件后缀、索引文件、预处理脚本、默认路径和 `os.path`/`Path` 拼接逻辑。

## 输出

分别列出官方数据准备流程、源码实际期望的目录树、配置键、预处理命令和数据完整性检查。下载命令仅作为未执行的说明。

## 只读验证

允许检查路径是否存在、列出少量目录项、读取元数据和静态解析预处理脚本。禁止下载、解压大文件、重写索引或运行会产生产物的预处理。

## 常见误判

- 数据集名称相同但版本、划分或预处理格式不同。
- README 示例路径不一定是代码默认路径。
- 相对路径应以入口脚本工作目录而非仓库根目录为准。
