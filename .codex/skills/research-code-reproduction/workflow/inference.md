# 测试、评估与推理分析

## 检查目标

定位测试入口、指标计算、单样本推理、批量推理、结果保存和论文指标对应关系。

## 优先位置

搜索 `evaluate`、`test`、`predict`、`inference`、metric 函数、结果写入和 checkpoint 加载调用。确认模型处于 eval 模式及数据划分。

## 输出

区分官方评估命令、源码可确认的推理命令、仅由 README 声明的命令和推断命令。说明输入格式、权重、输出格式、指标和结果位置。

## 安全边界

默认不执行推理或评估；即使命令看似只读，也可能写结果、缓存或可视化文件。仅执行用户明确允许且已确认不会写入目标仓库的轻量帮助检查。

## 常见误判

- 测试脚本可能默认读取训练输出目录。
- 指标实现可能与论文同名指标的定义不同。
- 单图 demo 不一定覆盖批量推理接口。
