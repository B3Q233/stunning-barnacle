# 配置分析

## 检查目标

识别配置文件、命令行覆盖、默认值、设备、batch size、输出目录、随机种子、resume 和实验标签。

## 优先位置

读取 YAML/JSON/TOML、argparse 默认值、Hydra/OmegaConf 组合逻辑、shell 启动器和配置加载函数。记录参数最终优先级。

## 输出

用表格说明配置键、默认值、作用、来源、可覆盖方式和风险。区分论文设置、代码默认值和用户必须填写的值。

## 只读验证

允许解析配置、查看帮助、静态追踪覆盖逻辑和检查路径。禁止写回配置、生成实验目录或运行入口验证覆盖行为。

## 常见误判

- shell 参数可能覆盖 YAML 默认值。
- 配置中的相对输出路径可能随工作目录变化。
- 多卡参数不一定表示代码支持任意 GPU 编号。
