# 环境分析

## 检查目标

提取操作系统、Python 版本、框架版本、CUDA/cuDNN、编译扩展、依赖安装方式和 GPU 要求。

## 优先位置

读取依赖锁定文件、容器文件、安装脚本、CI 配置和源码中的版本断言。区分运行必需依赖、训练专用依赖、评估专用依赖和可选工具。

## 输出

给出环境矩阵、安装顺序、环境变量、设备参数和轻量验证命令。命令必须标注来源和是否执行过。

## 只读验证

允许 `python --version`、`pip --version`、框架导入与版本查询、`nvidia-smi`、读取环境变量和静态依赖检查。禁止 `pip install`、conda 创建/更新、编译扩展和下载。

## 常见误判

- requirements 未必锁定 CUDA 对应的 PyTorch wheel。
- README 的 GPU 型号通常是作者环境，不一定是硬性要求。
- import 成功只能证明包可导入，不能证明训练环境完整。
