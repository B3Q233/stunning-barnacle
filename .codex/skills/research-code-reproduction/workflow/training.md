# 训练流程分析

## 检查目标

追踪训练入口、数据加载、模型构建、优化器、学习率调度、保存 checkpoint、日志和恢复训练流程。

## 优先位置

从入口脚本的参数解析开始，继续追踪 Trainer/Experiment、训练循环、loss、optimizer、scheduler、保存函数和日志初始化。

## 输出

给出源码确认的训练命令模板、运行目录、关键参数、保存产物和停止条件。命令必须标注“未执行”，除非只是帮助或静态检查。

## 安全边界

绝不执行训练、dry-run 不明的训练入口、会初始化 wandb/TensorBoard 写入的命令或会生成 checkpoint 的脚本。

## 常见误判

- README 命令可能缺少必要的工作目录或环境变量。
- `--eval` 可能仍加载并写入缓存；需读源码确认。
- 恢复训练的 checkpoint 与纯推理权重可能不是同一格式。
