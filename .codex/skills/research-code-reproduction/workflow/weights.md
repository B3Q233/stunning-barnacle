# 权重与检查点分析

## 检查目标

定位预训练权重、checkpoint 命名、下载地址、放置目录、加载函数、键名转换和结构校验。

## 优先位置

搜索 `torch.load`、`load_state_dict`、`from_pretrained`、`resume`、`checkpoint`、`weights`、URL 和默认权重路径。核对配置与加载代码是否一致。

## 输出

列出权重类型、适用模型、文件名/目录、来源、放置位置、加载参数、是否必须预训练以及验证方法。无法确认大小、哈希或兼容性时明确标记。

## 只读验证

允许检查本地文件存在性、文件大小、配置和静态加载路径。禁止下载权重、修改软链接、覆盖 checkpoint 或启动加载后会写缓存的程序。

## 常见误判

- README 链接可能失效或指向不同模型版本。
- `strict=False` 不代表权重完全兼容。
- checkpoint 可能包含优化器、epoch 和模型状态，不能只看文件名。
