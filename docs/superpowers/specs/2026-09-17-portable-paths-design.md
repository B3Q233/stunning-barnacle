# 入库文件可迁移性（禁止绝对路径）——设计文档

> 日期：2026-09-17
> 状态：待人工审阅（用户指令直接给出：写进 AGENTS.md 并修复）
> 前置文档：`docs/superpowers/specs/2026-09-02-config-canonical-design.md`
> 关联：`TPA/tests/test_portable_paths.py`（既有运行期路径解析测试）

## 1. 背景

仓库大量入库文件（代码注释、USAGE、spec/plan、技能文档、测试）里写死了本机
绝对路径：盘符 + 仓库目录名开头，以及本机程序安装目录。盘点结果（git 跟踪文件，
排除二进制）：

| 类别 | 命中文件 | 命中行 |
|---|---|---|
| 本机仓库根前缀（盘符绝对路径） | 80 | 418 |
| 其中 TPA/ | 49 | — |
| 其中 docs/ | 21 | — |
| 其中 .codex/skills/（.gitignore 白名单内的技能） | 9 | — |
| AGENTS.md | 1 | 3 |

除仓库根前缀外还有三类：

1. 本机程序安装目录（浏览器可执行文件探测）；
2. 文档示例中的"外部盘符占位路径"（跨数据集实验示例）；
3. 被 .gitignore 排除的本地资产目录（论文库、MinerU 资产、.claude 技能镜像）被当作
   真实路径写进文档或技能说明。

风险：

- **不可迁移**：换机器/换盘符/换用户名后所有命令示例失效；在 Linux 上按错误的
  绝对路径执行会在当前目录建出 `盘符:/...` 形式的多余目录（历史上已发生过）。
- **隐私**：把本机目录结构与用户名写进版本库并推送到远端。
- **CI/协作**：贡献者无法照抄命令复现；review 时无法判断路径是否真实存在。

## 2. 目标与不变量（可验收条款）

### R1 入库文本零绝对路径

所有 git 跟踪文本文件（代码 / 注释 / 配置 / 文档 / spec / plan / USAGE / DESIGN /
测试 / 技能）不得出现绝对路径，包括：

- Windows 盘符路径（盘符 + 冒号 + 分隔符，反斜杠与正斜杠、大小写、双反斜杠转义形式）；
- UNC 路径（双反斜杠 + 主机名 + 共享名）；
- POSIX 用户/系统目录路径（`/home`、`/Users`、`/root`、`/mnt`、`/usr` 开头的绝对路径）；
- 本机程序安装目录与用户名目录。

验收：`TPA/tests/test_no_absolute_paths.py` 扫描全部跟踪文本文件，命中即失败；
`git grep` 复查零命中。

### R2 只引用仓库内可迁移位置

入库文件只能引用两类路径：

1. **仓库内相对路径**（相对仓库根），例如 `TPA/models/lightgcn/config.yaml`、
   `docs/superpowers/plans/...`；
2. **占位符或环境变量**，用于确实位于仓库外或未入库的资产：
   `<repo>`（仓库根）、`<papers>`（本地论文库）、`<MinerU-Skill>`、
   `%TEMP%` / `$TMPDIR`（临时目录）、`%ProgramFiles%`（程序安装根）。

禁止把未入库目录（`.gitignore` 中的 `papers/`、`MinerU-Skill/`、`.claude/`）写成
真实绝对路径。

### R3 命令示例可跨机复制

解释器与脚本一律写成占位符或相对形式：

- 首选：`python -m unittest ...`（已激活仓库根 `.venv`）；
- 显式：`<repo>\.venv\Scripts\python.exe -m unittest ...`（Windows）、
  `<repo>/.venv/bin/python -m unittest ...`（POSIX）；
- 仓库内文件引用写相对仓库根路径，并注明工作目录。

不得出现形如"盘符 + 冒号 + 仓库目录"的解释器路径。

### R4 强制校验，且校验本身可证伪

- 新增的守护测试必须覆盖 R1 的四种形态，且有一条"反向用例"证明它不是恒真测试：
  用运行时拼接出的绝对路径样例断言检测器能命中（拼接写法保证测试文件自身不含
  字面绝对路径）。
- 允许清单（allowlist）默认为空；确需保留的字面样例必须逐条写明原因。

## 3. 替换规范（唯一映射表）

| 原写法（本机仓库根前缀） | 替换为 | 说明 |
|---|---|---|
| 仓库根 + `\.venv` 前缀 | `<repo>\.venv` | 解释器；跨机可复制 |
| 仓库根 + `\TPA` 前缀 | `TPA` | 相对仓库根 |
| 仓库根 + `\.codex` / `\.claude` / `\tmp` | `.codex` / `.claude` / `tmp` | 相对仓库根（后两者为本地镜像/中间产物） |
| 仓库根 + `\AGENTS.md` / `\.gitignore` / `\requirements.txt` | `AGENTS.md` / `.gitignore` / `requirements.txt` | 相对仓库根 |
| 仓库根 + `\papers` 前缀 | `<papers>` | 未入库资产占位符 |
| 仓库根 + `\MinerU-Skill` 前缀 | `<MinerU-Skill>` | 未入库资产占位符 |
| 裸仓库根 | `<repo>` | 无子路径时 |
| 外部盘符占位（文档示例） | `outputs/<tag>/...` | 改成仓库内相对示例 |
| 本机程序安装目录 | 环境变量拼接 / `shutil.which` | 代码走运行期探测；文档删除具体路径 |

大小写、正斜杠、双反斜杠转义三种变体同等处理。

## 4. 设计

### 4.1 组件

```text
AGENTS.md                              新增「路径与可迁移性（必须）」章节（R1–R4）
TPA/tests/test_no_absolute_paths.py    新增守护测试（扫描 git 跟踪文本文件）
TPA/tests/test_portable_paths.py       既有断言里的字面盘符样例改为正则断言
.codex/skills/knowledge-point-visualization/scripts/verify_outputs.py
                                      浏览器探测改为环境变量 + shutil.which
其余 ~78 个跟踪文本文件                 按 §3 映射表做机械替换
```

### 4.2 守护测试设计

```python
ABS_RE   = re.compile(r"(?<![A-Za-z0-9])[A-Za-z]:[\\/]")          # 盘符
POSIX_RE = re.compile(r"(?<![A-Za-z0-9.])/(?:home|Users|root|mnt|usr)/")
UNC_RE   = re.compile(r"\\\\[A-Za-z0-9._-]+\\[A-Za-z0-9._$-]+")   # UNC
```

- 文件清单来自 `git ls-files`（与"入库文件"定义一致）；
- 跳过二进制扩展名（图片/权重/序列化）与无法按 UTF-8 解码的文件；
- 失败信息给出 `文件:行号: 命中内容`，便于定位；
- 反向用例：用 `"G" + ":" + "\\" + "Idea"` 之类的运行时拼接构造样例，断言检测器命中。

### 4.3 命令示例的工作目录语义

`<repo>\...` 形式自带根锚点，不受"工作目录"标注影响；因此文档里的
"工作目录 `TPA`"标注可以保留，命令依旧可跨机复制。这也避免了为每份文档重算
相对层级（`..\.venv\...` 之类）带来的二次错误。

### 4.4 错误处理

- 机械替换只作用于 UTF-8 可解码的跟踪文本文件；不触碰数据文件与历史产物。
- 替换脚本先 dry-run 输出"文件 → 命中数"，确认后再写入；写回用二进制模式，
  避免换行符被整体重写（控制 diff 规模）。
- 替换后立即运行守护测试；若仍有命中，逐条人工确认（外部盘符示例、
  程序安装目录）再修。

## 5. 范围

**在范围内**：AGENTS.md 规则、守护测试、80 个跟踪文本文件的路径改写、
`verify_outputs.py` 的程序探测改造、既有 `test_portable_paths.py` 断言的去字面化。

**不在范围内**：不修改数据文件与历史产物；不删除/新增跟踪文件；不改变
`.codex/skills` 的跟踪策略（`.gitignore` 已用白名单显式保留技能）；不改业务逻辑、
指标语义、配置键。

## 6. 验收判据

1. `python -m unittest tests.test_no_absolute_paths -v` 通过（含反向用例）。
2. 扫描结果为零命中（`git grep` 复查）。
3. `python -m unittest discover -s tests -t .` 与 pre 层测试全绿。
4. AGENTS.md 含 R1–R4 四条规则与 §3 映射表要点，且 AGENTS.md 自身零命中。
5. 抽查三条命令示例（模型训练、攻击批跑、技能脚本）可跨机替换 `<repo>` 后直接执行。

## 7. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 机械替换误伤（例如把 URL、数学文本改写） | 只匹配"盘符 + 冒号 + 分隔符"且左侧非字母数字；替换前 dry-run 人工抽查 |
| 文档示例语义变化（宿主/工作目录） | 统一用 `<repo>` 锚点，保留原工作目录标注 | 
| 技能脚本探测浏览器失效 | 改为 `%ProgramFiles%` 拼接 + `shutil.which` 双通道，保持原回退顺序 |
| 换行符被整体改写 | 二进制读写 + `newline` 不转换 |
| 回滚 | 按文件粒度 `git checkout` 即可；守护测试可随回滚一并撤回 |
